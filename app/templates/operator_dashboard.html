Edge Court — live per-sleeve verdict
Is each sleeve ACTUALLY earning? Verdict from REALIZED closed trades only (forced/admin closes excluded), cost-net, with a 95% CI and a 20 independent-trading-day minimum. The sample is day-clustered: multiple lots closed in the same instant, and multiple names closed by one same-day rebalance, are ONE correlated observation — not many — so a single close can't masquerade as a proven track record (counting rows independently inflated the t-stat by ~√(fake n)). Low-turnover sleeves (trend, managed_futures) close ~quarterly, so a close-based gate is unreachable — they're verdicted instead on non-overlapping periodic book returns (return-on-deployed capital, rebalance-flow periods excluded), which proves live earning power on held capital, not market-neutral alpha. Realized P&L is fill-reconciled on every sleeve — condor closes, momentum equity exits, AND long-option exits: a close priced from an estimate/quote is upgraded to the actual broker fill (never fabricated when unconfirmed), and a CLOSED position the broker still holds is reverted to OPEN (never counted as a realized win). Execution = measured slippage (decision-mid vs fill) shown beside the edge — pair them: measured cost > edge ⇒ retire. Daily open-marks are autocorrelated and never used here.
